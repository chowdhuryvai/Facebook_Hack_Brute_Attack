## 📖 OVERVIEW

**Facebook ID Finder** is an advanced cybersecurity tool designed to extract numeric Facebook profile IDs from any Facebook URL. It employs a sophisticated 5-phase extraction system that combines multiple techniques including HTML parsing, API queries, redirect analysis, online services, and comprehensive regex pattern matching.

### Why This Tool?

- 🔍 **Universal Compatibility**: Works with ANY Facebook URL format
- 🔒 **Hidden Profile Support**: Can extract IDs from private/hidden profiles
- 🚀 **Multi-Phase Approach**: If one method fails, automatically tries others
- 🎨 **Professional UI**: Beautiful, colorful terminal interface with progress indicators
- 📦 **Zero Configuration**: Auto-installs all dependencies on first run
- 💾 **Result Logging**: Automatically saves found IDs and test results

> **⚠️ IMPORTANT**: This tool is created for **EDUCATIONAL PURPOSES ONLY**. Always obtain proper authorization before testing any account.

🚀 USAGE
💻 Command Line
python fb.py [OPTIONS]

OPTIONS:
  -t, --target    Target email address, phone number, or profile ID
  -w, --wordlist  Path to wordlist file for dictionary attack
  -s, --single    Single password to test against target
  -p, --proxy     HTTP/HTTPS proxy server (format: IP:PORT)
  -g, --getid     Facebook profile URL to extract numeric ID
  --build         Build standalone Windows executable (.exe)
  -h, --help      Show help message and exit
